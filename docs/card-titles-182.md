# Release182

The934 collectible cards, including155 Synchros, now have unique stable German and English names keyed by existing IDs.609 generic or duplicated names are replaced using authored element/effect vocabulary;325 existing distinct names remain. Registration updates only incoming card names, never scans the whole catalog on repeated registrations. Card ownership, costs, rarity, effects, IDs and saves are unchanged. Team cards show their existing owner-specific name rather than the same generic Grundangriff title.

One high-specificity title rule replaces conflicting legacy strong/line-clamp rules. The title has a dedicated11% height with two readable lines, centered content and no clipping. Synchro names sit below material sockets and above effects. Background geometry/art remains untouched.

Validation: unique bilingual catalog, full-name English roundtrips, registry/save/mechanics equivalence, measured text at110/126/180/340px card widths, renderer structure and full regression suite. No browser/phone/GPU verification. Original art and movement unchanged.
