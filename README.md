# MONORA × NACHTSIEGEL v1.3 — Originalwelt wiederhergestellt

## Start auf Android
1. Die ZIP-Datei vollständig entpacken.
2. `MONORA-NACHTSIEGEL-v13/index.html` im Browser öffnen.
3. Die ursprüngliche MONORA-Wildnis mit der ursprünglichen Karte und den Bewegungsknöpfen benutzen.
4. Unten sind die vier zusätzlichen Menüpunkte **Monster**, **Deck**, **Karten** und **Booster** erreichbar.

## Spielsystem
- Die MONORA-Erkundungsoberfläche bleibt im Originaldesign.
- Vier Monster im Team, weitere im Lager; Monster sind keine Aktionskarten.
- Das Deck besteht aus Angriffen, Zaubern und Unterstützung; Elementangriffe erfordern ein passendes aktives Monster.
- Wildkämpfe sollen den gemeinsamen Kartenkampf verwenden.

## Hinweis
Diese Version ist eine gezielte Rücknahme der Änderungen an der Weltansicht, keine garantierte Reparatur sämtlicher Kampffehler. Bitte vorherige Spielstände nicht löschen. Bei lokal geöffneten Dateien können Android-Browser unterschiedliche Einschränkungen haben.
